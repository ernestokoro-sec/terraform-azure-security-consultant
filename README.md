# Azure Cloud Security Engineering | Terraform Portfolio

## Overview

An independent, hands-on Azure Cloud Security Engineering portfolio focused on designing, deploying, securing and validating enterprise-style Azure infrastructure using Terraform.

The project demonstrates practical cloud security engineering, identity and access management, network segmentation, hybrid connectivity, infrastructure automation and operational troubleshooting.

**Project status:** Stage 18 completed. Stage 19 architecture capstone in planning.

## Technologies

- **Cloud:** Microsoft Azure
- **Infrastructure as Code:** Terraform
- **Identity & Access:** Microsoft Entra ID, Azure RBAC, managed identities and Key Vault
- **Networking:** Azure VNets, subnets, NSGs, route tables, VPN connectivity and Azure Virtual WAN
- **Security:** Azure Firewall, private connectivity and network security controls
- **Engineering Tools:** Azure CLI, PowerShell, Git and GitHub

## Engineering Focus

### Azure Infrastructure and Networking

Provisioning and configuring Azure infrastructure using reusable Terraform modules, environment-specific variables and remote state management.

### Cloud Network Security

Implementing network segmentation, security rules, route controls, private connectivity and secure hybrid networking.

### Identity and Access Management

Exploring and implementing identity-based security controls, Azure RBAC and secure authentication between workloads and Azure services.

### Terraform Engineering

Building reusable infrastructure modules, validating configuration changes and troubleshooting deployment issues.

### Security Validation and Troubleshooting

Using Azure Portal, Azure CLI, Terraform commands and operational evidence to verify configurations and investigate deployment problems.

## Project Progress

**Completed:** Stages 1–18, including infrastructure deployment, networking, security controls, hybrid connectivity and Terraform security hardening.

**Next:** Stage 19 — architecture capstone evaluating Hub-and-Spoke and Azure Virtual WAN approaches.

This is an independently developed technical portfolio, not a claim of customer production deployment.
